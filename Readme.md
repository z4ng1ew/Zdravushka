IVR (Interactive Voice Response) — голосовое меню по телефону: «Для записи нажмите 1, для справки — 2». В поликлинике оно уже есть. По кейсу Здравушка работает поверх него, а не вместо: например, пункт меню «0 — живой оператор» остаётся. И по регламенту Здравушка не говорит «нажмите 1»: пациент просто говорит своими словами.
