# Стили

Обычный CSS без библиотек. Файлы подключаются в `app/layout.tsx` **строго по номеру** —
при равной специфичности побеждает правило, подключённое позже, поэтому номер = место в каскаде.

| Файл | Что внутри |
|---|---|
| `01-theme.css` | цвета и переменные, шрифт, фон, крупный шрифт (`html.big-font`) |
| `02-layout.css` | страница, панели, шапка, сетки |
| `03-buttons.css` | кнопки и ссылки |
| `04-badges.css` | бейджи, плашки статусов (`sp-*`, `tag-*`, `rtag-*`), плашка МИС |
| `05-tooltip.css` | всплывающие подсказки `data-tip` |
| `10-call-mic.css` | экран звонка: приветствие, статус, микрофон, кнопки звонка |
| `12-call-dialog.css` | лента диалога, реплики, поле ввода, быстрые фразы |
| `13-call-details.css` | нижняя панель «Что понял Здравушка» / «Запись на приём» |
| `20-cabinet-shell.css` | кабинет регистратора: меню слева, шапка |
| `21-cabinet-blocks.css` | показатели, очередь, обзвон, журнал, «Диалоги», ошибки, настройки |
| `30-tickets.css` | талоны |
| `31-schedule.css` | расписание |
| `32-stats.css` | статистика |
| `40-responsive.css` | планшет и телефон, печать, «меньше анимации» — **после** экранов, чтобы перекрывать их |
| `41-a11y.css` | рамка фокуса с клавиатуры — последней |

Правила:
- Новый класс — в файл своего экрана; общий — в 02–05.
- `@media` — только в `40-responsive.css`. Если адаптивное правило не должно задевать
  какой-то блок, исключаем его явно (пример: `.panel:not(.bottom-wrap)`), а не порядком файлов.
- Жёлтый цвет не используем (решение по дизайну).
- Классы, которые собираются в коде по префиксу (`rtag-${tone}`, `sec-…`, `ava-${speaker}`), не удалять,
  даже если поиск по точному имени их не находит.
