## Инструкция для Муслима

> **Муслим, как подключить фронт к API Здравушки**
>
> **1. Забрать проект**
> ```bash
> git clone https://github.com/z4ng1ew/Zdravushka.git
> cd Zdravushka
> python3 -m venv .venv
> source .venv/bin/activate
> pip install -r requirements.txt
> uvicorn app.main:app --reload --port 8000
> ```
> Проверка: открой http://localhost:8000/api/health, там должно быть `{"status":"ok"}`.
> Вся документация API с кнопками «попробовать» — на http://localhost:8000/docs.
>
> **2. Как разговаривать с API — один адрес: `POST /api/chat`**
>
> Начало звонка: отправь пустой текст без session_id:
> ```json
> {"session_id": null, "text": ""}
> ```
> Ответ — приветствие и `session_id`. **Сохрани session_id** и отправляй его с каждой следующей репликой:
> ```json
> {"session_id": "a1b2c3d4e5f6", "text": "хочу записаться к терапевту"}
> ```
> Пример на JavaScript:
> ```js
> const API = "http://localhost:8000";
> let sessionId = null;
>
> async function send(text) {
>   const r = await fetch(`${API}/api/chat`, {
>     method: "POST",
>     headers: {"Content-Type": "application/json"},
>     body: JSON.stringify({session_id: sessionId, text})
>   });
>   const data = await r.json();
>   sessionId = data.session_id;
>   return data;
> }
> // Новый звонок: sessionId = null; await send("");
> ```
>
> **3. Что приходит в ответе и что с этим показывать**
>
> | Поле | Что это | Что рисовать |
> |---|---|---|
> | `reply` | Фраза Здравушки | Пузырь в ленте диалога (слева). Позже — озвучка |
> | `intent` | Цель звонка: `booking`, `reschedule`, `cancel`, `status`, `info`, `escalation` | Бейдж «Намерение» в панели «Что понял бот» |
> | `collected` | Что бот уже узнал: `{"ФИО": "...", "дата рождения": "...", "специальность": "..."}` | Карточки с галочками в правой панели |
> | `options` | До 3 вариантов времени: врач, `scheduled_at`, `spoken` | Кнопки-варианты. По клику отправь `"1"`, `"2"` или `"3"` |
> | `booking` | Выбранная или созданная запись | Карточка записи. Если `status` = «Запланирована» — плашка «Записано в МИС ✓» |
> | `escalation` | Перевод на человека: `rule`, `reason`, `priority`, `emergency`, `summary` | Оранжевый баннер с причиной. Если `emergency: true` — **красный** блок «Звоните 103 / 112» |
> | `done` | Разговор окончен | Заблокировать ввод, показать кнопку «Новый звонок» |
>
> Поля могут быть пустыми (`null`, `[]`, `{}`). Фронт не должен из-за этого падать.
>
> **4. Сценарии, чтобы проверить все экраны**
> - Запись: `""` → «хочу записаться к терапевту» → «Иванов Иван Иванович» → «01.01.1990» → «2» → «да»
> - Отказ от варианта: на вопросе «Верно?» ответить «нет» — бот снова покажет варианты
> - Экстренный случай: «у меня болит грудь» → красный блок
> - Оператор: «позовите оператора» → перевод
>
> **5. Важно**
> - Сейчас бот **ненастоящий**: работает по ключевым словам и в МИС не пишет. Формат ответов уже окончательный. Когда подключим настоящий мозг, твой фронт продолжит работать без изменений.
> - Если нужно новое поле в ответе — **сначала напиши Мовсару**, поля меняем только вместе (файл `app/models.py`).
> - Голос пока не делаем. Будет отдельный адрес для аудио, сообщим.
>
> **6. Git — работаем в своей ветке**
> ```bash
> git checkout -b frontend
> # фронт клади в папку static/ (index.html, css, js)
> git add static/
> git commit -m "Фронтенд: экран звонка"
> git push -u origin frontend
> ```
> В `master` не пушь: Мовсар сам сольёт ветку после проверки. Файлы в `app/` не трогай. Если что-то нужно поменять в API — пиши.
>
> **7. Где будет лежать фронт**
> Итоговые файлы — в папке `static/`. Тогда сервер сам отдаёт их по адресу http://localhost:8000/, а на демо всё работает с одного порта 8000. Если пишешь на React или Vue — собирай (`npm run build`) в папку `static/`. Если делаешь чистый HTML/JS, ещё проще: файлы сразу в `static/`.
